# The Coroner: Autopsy Mod

**A complete forensic pathology system for Project Zomboid Build 42.**
Examine bodies, estimate the time of death, find the cause of death, perform a hands-on autopsy and harvest organs, all while training your **First Aid** skill without cutting yourself to pieces in the bathroom.

## Quick start
1. Find a **table at least 2 tiles long**, a **scalpel**, **forceps or tweezers** and something to cut ribs (**bone saw**, **bolt cutters** or any **saw**).
2. Make sure there is **light**: a lamp nearby or a lit flashlight.
3. **Right-click a corpse or the table → Coroner → Place corpse on table**.
4. **Undress the torso**, then **Coroner → Perform an autopsy**.
5. Grab a **thermometer** and use **Coroner → Estimate time of death** to examine the body and find out how and when it died.
